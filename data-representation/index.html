1. Introduction

In computer science area, we can deem that the basic information component is the bit streams representing by 0, 1 string. Based on 0 and 1 bit streams, we have developed information patterns such as text, images, videos, and audio that can be intuitively understood by humans.

1. RGB Principal

1. The visual mechanism of the human eye provides a basis for describing color using three quantities.

Light possesses various spectral compositions. Upon entering the eye, light stimulates photoreceptor cells, and the visual system subsequently generates the perception of color based on these stimuli.

In humans with normal vision, photopic (daylight) vision relies primarily on three types of cone cells, each exhibiting a distinct response to different ranges of light wavelengths. Consequently, under specific viewing conditions, the stimulation of these three types of cells by a given light source can be characterized by three distinct quantities.

This implies that even if two light sources have different spectral compositions, they can still be perceived as the same color, provided they elicit identical levels of stimulation across these three types of cone cells.

This principle serves as the foundation for display devices to reproduce a wide range of colors using only a limited number of light sources.

2. A specific range of colors can be reproduced by adjusting red, green, and blue light.

By selecting red, green, and blue as primary colors and independently controlling the intensity of each, display devices can generate a diverse array of color perceptions.

For instance, an appropriate mixture of red and green light is perceived by the human eye as yellow.

Thus, any color that can be reproduced using this set of primary colors can be described by three individual components:

  • Red Component
  • Green Component
  • Blue Component

3. Image Storage

3.1 From Image to Bits

How to store an image in the computer?

A common way is: from left to right in each row, and from top to bottom between rows. This is called row-major order.

Assume that each pixel has three color channels (RGB) and each channel takes 8 bits. So a single pixel needs 3B space. 6 pixels take 3 * 6 = 18B in total.

Offset refers to the byte offset relative to the start of this pixel data, starting from 0.

So if we have the image’s binary information . If we want to know the 5th pixel’s color, we can infer that the 5th pixel’s offset number is 3 * (5 - 1) = 12.

General Formula for Row-Majored Order:

3.4 RGBA (Transparency)

RGBA is an extension format of RGB with an extra channer Alpha to describe the transparency.

Why we need Alpha to describe the transparency?

Suppose we want to place a red icon on a blue background. The icon might have areas that completely cover the background, or it might have transparent or semi-transparent areas.

RGB can only describe the color of a pixel; it can’t tell us how it should blend with the background on its own.

Alpha Value Meaning
255 Completely Opaque
128 Half Opaque
0 Completely Transparent

For instance, a red pixel can have different alpha value:

Place the red pixels on a blue background: - Alpha 255: The spot shows the foreground red, completely covering the background. - Alpha 128: The foreground red and background blue both affect the final color. - Alpha 0: The foreground doesn’t contribute color, so the spot shows the background blue.

3.5 Grayscale Image

As we said above, we can use RGB combination to illustrate a specific range of colors. There’s a phenomenon: when R = G = B, we will get black, white and gray.

RGB value Appearance
(0, 0, 0) Black
(64, 64, 64) Darker Gray
(128, 128, 128) Gray
(192, 192, 192) Lighter Gray
(255, 255, 255) white

For this kind image, we can use single-channel to represent the color instead of using three kinds.

Grayscale pixels usually only keep one gray value.

Using the common 8-bit grayscale format, usually called Gray8:

Each pixel only includes a gray value:

  • 0 for black
  • 255 for white
  • middle values indicate different shades of gray
