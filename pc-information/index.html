Windows does not report the keyboard model — it only appears as HID Keyboard Device behind a 2.4 GHz receiver. The receiver enumerates as USB\VID_1038&PID_203A (vendor ID 0x1038 is SteelSeries), which means the wireless link uses a SteelSeries chipset. The details above come from the label on the back of the keyboard.

10.1.1 How to Charge

The keyboard has one USB-C port (key-line separation). Charging goes through it — plug the included cable into any USB port or a 5 V charger.

A common confusion: the magnet on the back of the keyboard is only a storage bay for the 2.4 GHz receiver, not a charger. There are no electrical contacts inside it. The receiver itself never needs charging — it draws power from the USB port it is plugged into.

10.1.2 How to Check Battery Level

This model ships without any companion software, so there is no percentage readout:

Method Works?
Vendor software ❌ None exists for this model
Windows Settings (Bluetooth & devices) ❌ The dongle is not a Bluetooth device
Win32_Battery / powercfg ❌ Only reports the laptop battery
Keyboard indicator LED ✅ The only option

The official spec sheet does not publish a battery capacity or battery life figure. Backlight is the biggest variable — turn it off to extend runtime considerably.
