3.2.1 随机变量

现象:

  • 确定性现象;
  • 随机现象: 在一定的条件下,并不总出现相同结果的现象 (手性分子)
    • Feature 1: 结果不止一个
    • Feature 2: 事先不知道出现哪一个
    • 统计规律: 符合统计规律
  • 随机试验: 在相同条件下可以重复的随机现象
    • 随机性
    • 可重复性
    • 可观察性
    • 有些随机现象是不能重复的, 比如某场足球比赛的结果

3.2.2 样本空间

  • 样本点 (\(\omega\)): 随机试验的每一个可能的结果
  • 样本空间 (\(\Omega\)): \(\Omega=\{\omega\}\) , 是样本点构成的集合
    • e.g. Lifespan of a Television: \(\Omega = \{t, t>= 0\}\)
  • 离散样本空间: 样本点连续, 克列
  • 连续样本空间: 样本点连续不可列个

3.3.3 随机事件

  • 随机事件: 某些样本点组成的集合, 是\(\Omega\)的子集, 用 \(A,B,C\) 表示
  • 基本事件: \(\Omega\) 的单点集
  • 必然事件: \(\Omega\)
  • 不可能事件: \(\Phi\)
  • e.g. 掷1次骰子:
    • 基本事件
    • 随机事件: \(A = \{2, 4, 6\}\)
    • 必然事件: \(A \leq 6\)
    • 不可能事件: \(A > 6\)

3.3.4 随机变量

  • 随机变量: 表示随机现象结果的变量, annotated as \(X,Y,Z\)

3.3 Basic Concepts of Stochastic Processes

3.3.1 Definition of Stochastic Processes

A stochastic process is a family of random variables indexed by time.

  • Let \((\Omega,F,P)\) be a probability space and \(T\) an index set.

    • \(\Omega\): Sample Space
    • \(F\): Set of event. \(F\) is a subset of \(\Omega\).
    • \(P\): A function defined on sample space \(\Omega\).
    • \(T\): A parameter set. \(T\) is a subset of \(R\).

    A stochastic process is a collection of random variables \(\{X_t: t \in T\}\) defined on \((\Omega,F,P)\), where each \(X_t\) takes values in a state space \(S\).

  • From the view of mathematics, \(\{X_{(\omega,t)}: t \in T\}\) is a function defined on \(\Omega \times T\).

    • $$ is a sample point
    • $tT $ is a parameter.
